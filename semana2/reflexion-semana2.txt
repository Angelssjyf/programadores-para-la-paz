Saber usar la terminal es importante para un 
desarrollador porque permite trabajar de forma 
más rápida y organizada dentro de un proyecto. 
A través de la terminal se pueden crear carpetas, 
mover archivos y ejecutar comandos sin necesidad de 
usar la interfaz gráfica. Además, muchas herramientas
 de programación y control de versiones como Git 
 funcionan principalmente desde la terminal. 
 También ayuda a automatizar tareas y 
 facilita el trabajo en diferentes sistemas 
 operativos. Un desarrollador que domina la terminal
  puede tener mayor control sobre sus proyectos y 
  resolver problemas de manera más eficiente. 
  Por eso aprender a usar comandos básicos es una 
  habilidad fundamental en el mundo del desarrollo
   de software.
