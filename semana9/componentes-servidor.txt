Sistema operativo:
Es el software principal que administra los recursos del computador o servidor. Permite ejecutar aplicaciones y gestionar archivos, memoria y procesos.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript en el servidor. Se utiliza para crear aplicaciones web y APIs.

Aplicación server.js:
Es el archivo donde se encuentra la lógica del servidor. Define las rutas y las respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación que permite al servidor recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan eventos, actividades y errores del sistema. Ayudan a monitorear y solucionar problemas del servidor.
